# VELMARA — The Poster for a Place That Isn't There

A travel poster for a place that does not exist: **VELMARA, the floating
isles of the Amber Sea** — islands that drift above a golden sea at dusk,
their waterfalls falling into the sky.

`main.ts` (Node 22, standard library only, no network) paints the poster
procedurally, pixel by pixel — dusk sky, art-deco sun, floating islands,
the Amber Sea — and writes a 1024×1024 PNG to `/output/entry.png`.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
